# 08: Fix Mirrored Card Score on Reveal and Arena Component Vertical Stacking

**Category:** bug
**Status:** done
**Blocked by:** None

## Description
When voting concludes and cards are revealed:
1. The score number rendered on the card face is mirrored horizontally (e.g. `5` renders as `Ƨ`, `13` renders as `ƐƖ`).
2. Participant seat stacks (card + avatar + name + status badge) and the center status/consensus hub collide vertically on small player counts and compact table viewports (e.g. top player's "Voted" badge overlaps "ROUND 1 • REVEALED", and bottom player's card is partly obscured by the consensus card).

## Root Causes
1. **Mirrored Score**: In [`client/src/components/PokerCard.tsx`](file:///home/widi/GitHub/scrum-poke-ai/client/src/components/PokerCard.tsx), the card face container has the class `rotate-y-180`. Because it rotates the entire element 180 degrees on the Y-axis without a separate backface/inner-face container, the text inside is flipped into a mirror image.
2. **Component Stacking**: In [`client/src/components/PokerTableArena.tsx`](file:///home/widi/GitHub/scrum-poke-ai/client/src/components/PokerTableArena.tsx), 2-player seating uses `top: 18%` and `top: 80%` along the center line (`left: 50%`). Because each participant card stack is ~160px tall and the center consensus hub occupies `top: 50%` (~140px tall), the top player's badge collides with the center hub header, and the bottom player's card collides with the consensus card.
