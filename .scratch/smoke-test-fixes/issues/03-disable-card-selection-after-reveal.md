# 03: Disable Card Selection and Vote Modification After Reveal

**Category:** `bug`
**Status:** `closed`
**Blocked by:** none

## Problem Statement

After the Facilitator clicks "Reveal Cards" and the room enters the `Revealed` (or `Finalized`, `Discussing`, `Slicing`) phase, estimators are still able to click cards on the bottom deck to change or cast votes. In Planning Poker rules, votes must be locked once cards are revealed to prevent bias and tampering with the consensus result.

## Verified Codebase Behavior

1. In `client/src/views/RoomView.tsx` line 336:
   ```tsx
   <DeckSelector
     selectedCard={myVote}
     onSelectCard={handleCardClick}
     disabled={phase !== 'Voting' && phase !== 'Revealed'}
   />
   ```
   The `disabled` prop condition explicitly allowed voting during the `Revealed` phase (`phase !== 'Voting' && phase !== 'Revealed'`).
2. In `shared/src/room-reducer.ts`, `CAST_VOTE` does not guard against mutations when `state.phase` is `Revealed` or `Finalized`:
   ```typescript
   case 'CAST_VOTE': {
     const { participantId, vote } = action.payload;
     ...
   }
   ```
3. In `server/src/routes/rooms.ts`, the `/api/rooms/:code/vote` endpoint does not reject vote submissions when the round is already revealed or finalized.

## Agent Brief & Acceptance Criteria

- [ ] **Client UI Lock**: In `client/src/views/RoomView.tsx`, disable the `DeckSelector` whenever `phase !== 'Voting'` (cards are locked during `Idle`, `Revealed`, `Discussing`, `Slicing`, `Finalized`).
- [ ] **Server State Machine Invariant**: In `shared/src/room-reducer.ts`, reject/ignore `CAST_VOTE` actions if `state.phase !== 'Voting'` (and auto-transition from `Idle` to `Voting` if allowed).
- [ ] **REST Route Gating**: In `server/src/routes/rooms.ts`, return `400 Bad Request` if a participant attempts to vote when `phase` is `Revealed` or `Finalized`.
- [ ] **Automated Tests**: Add unit tests in `shared/src/__tests__/room-reducer.test.ts` and integration tests in `server/src/__tests__/server.test.ts` verifying that vote changes are rejected after reveal.
